## MASALAH UTAMA (harus dibereskan)
User lapor "banyak element overlapping" di desktop DAN mobile. Root cause yang sudah diidentifikasi:
1. `.pos-cart-actions` pakai grid kaku `grid-template-columns: 132px minmax(88px, 1fr) auto` — di lebar sempit kolomnya tabrakan.
2. `.pos-cart-list` `max-height: 32vh` terlalu sempit, item jadi cramped.
3. `.pos-checkout-panel` sticky + max-height + overflow clipping.
4. `.pos-torn-edge` (clip-path 12px) bisa overlap elemen tetangga.
5. Banyak padding/margin inkonsisten antar blok (header, list, pelanggan, payment).

## ARAH DESAIN (dari user: minimalist, fokus tipografi & kontras bersih)
- Tetap layout: sidebar kanan (desktop) + bottom drawer (mobile). JANGAN ubah pola ini.
- Minimalist = kurangi noise, spacing konsisten, kontras jelas. Fokus ke hierarki tipografi.
- Semua angka/harga pakai JetBrains Mono + tabular-nums (var(--font-mono)).
- Hierarki jelas: nama produk (tegas) > harga satuan (mono) > qty > aksi kecil.

## REDESIGN KERANJANG (PosCartPanel.jsx)

### Cart row — ganti grid kaku jadi layout flex sederhana
Struktur baru per item (1 baris utama + aksi di bawah, TANPA grid overlap):
```
[Nama produk ......................  Rp harga]
[Satuan · harga  ·  Diskon toggle]
[−  qty  +]        [hapus] [tahan]
```
- Baris 1: nama produk (flex 1, truncate) + harga net (mono, align right)
- Baris 2: meta kecil (satuan, harga satuan) + diskon (compact, collapsible)
- Baris 3: qty stepper (kiri) + tombol aksi (kanan: tahan, hapus)
- Gunakan Flex/antd Space, BUKAN grid template kaku. Pastikan TIDAK overlap di lebar 320-1400px.
- Hapus tombol & tahan jadi icon button kecil (32-40px tap target).

### Cart header
Sederhana: "Keranjang" + jumlah item (badge). Hapus teks "X baris transaksi" yang bikin rame.

### Item ditahan (held)
Tampil sebagai sub-section jelas, opacity 0.6, badge "Ditahan".

## REDESIGN PEMBAYARAN (PosPaymentSummary.jsx)

- Metode bayar: 4 tombol (Tunai/Digital/QRIS/Transfer) full-width equal, TANPA gap aneh.
- Diskon: compact (input + toggle Rp/%).
- Summary box: Subtotal, Diskon, TOTAL (mono besar), Kembalian.
- Tombol "Proses Pembayaran": oranye stabilo #FF6A2E, min-height 52px, block, jelas terpisah.

## FIX CSS (app.css)

1. `.pos-cart-row`: ganti `display: grid; gap: 10px` + `.pos-cart-actions` grid kaku menjadi layout flex column yang bersih. HAPUS `.pos-cart-actions` grid-template-columns kaku.
2. `.pos-cart-list`: naikkan max-height ke ~44vh, tambah padding konsisten.
3. `.pos-checkout-panel`: pastikan tidak clip — gunakan flex column dengan cart-list `flex: 1 1 auto; min-height: 0; overflow-y: auto`, dan payment form `flex-shrink: 0` (selalu terlihat).
4. `.pos-torn-edge`: pastikan `position: relative; z-index: 0` agar tidak overlap, atau hapus jika masih bermasalah (signature boleh dikorbankan demi bebas overlap).
5. Spacing konsisten: pakai satu skala padding (8/12/16px) untuk semua blok cart.
6. Dark mode `[data-theme="dark"]` tetap jalan.
