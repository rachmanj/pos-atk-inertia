Tambahkan opsi tampilan daftar produk di POS Kasir: List (tanpa image, DEFAULT) vs Grid (dengan image). Murni frontend. BACA DULU: resources/js/Components/Pos/PosProductGrid.jsx, resources/css/app.css (class .pos-product-*, .pos-category-strip, .pos-search-bar), resources/js/theme/colors.js.

## FITUR
1. Toggle tampilan produk: "List" (default) dan "Grid".
2. Default = List (tanpa image).
3. List view = baris kompak: nama produk (kiri), harga + stok (kanan). TANPA gambar/thumbnail.
4. Grid view = layout tile sekarang (dengan image/icon placeholder).
5. Pilihan tampilan DISIMPAN di localStorage (key misal "pos-view-mode") supaya kasir tidak perlu set ulang tiap buka.

## IMPLEMENTASI

### 1. PosProductGrid.jsx
- Tambah state viewMode (useState), inisialisasi dari localStorage, default "list".
- Tambah UI toggle di area search bar / header produk. Gunakan antd Segmented atau Button group: [List] [Grid]. Icon: UnorderedListOutlined (List) dan AppstoreOutlined (Grid).
- Saat viewMode = "list": render daftar produk sebagai baris kompak (bukan tile). Tiap baris: nama produk + meta (PPOB/Layanan/Stok) + harga (mono). Klik baris = add to cart (sama seperti tile).
- Saat viewMode = "grid": render tile seperti sekarang (TANPA perubahan perilaku).
- Badge "Habis"/"PPOB"/"Layanan"/"Bahan menipis" tetap tampil di kedua mode.
- Simpan viewMode ke localStorage tiap kali berubah.

### 2. app.css
- Tambah class .pos-product-list + .pos-product-list-row untuk tampilan list:
  - Row: flex, align center, padding 10px 14px, border-bottom 1px solid #C9C4B4 (atau #EFEDE3), background #FFFFFF.
  - Hover: background #EFEDE3 (atau subtle).
  - Nama produk: flex 1, truncate, font-weight 600.
  - Harga: JetBrains Mono tabular, align right, warna #2A3B8F.
  - Stok/meta: kecil, warna sekunder.
  - Tap target minimal 44px (mobile).
- Dark mode variant [data-theme="dark"] untuk .pos-product-list-row.
